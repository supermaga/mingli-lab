  # 命理调试台 · mingli-lab

  紫微斗数排盘 + 梅花易数占卜的纯前端调试工具——完整展示每一步算法过程，可校验、可学习。

## 亮点

- **紫微斗数** —— 三合派口径，真太阳时经度校正、闰月按月处理（iztro 引擎）、晚子时规则，命主按乾坤地支（《紫微斗数全书》正典口径）
- **梅花易数** —— 时间起卦（年支序数 + 农历月日计卦）与数字起卦双入口，问事类别 / 详情可选
- **反推时辰定盘** —— 出生时辰不确定时，按已知信息反推校验
- **零依赖** —— 纯前端双击即用，深色界面
